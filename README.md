# ElevanceSkills YouTube Internship Project

A full-stack YouTube-style video streaming platform developed as part of my ElevanceSkills internship.

## Project Overview

This project is based on the provided YouTube-style training project and is being extended with additional features required for the internship.

The application allows users to browse videos, view video information, and interact with a YouTube-style interface.

## Technologies Used

### Frontend
- Next.js
- TypeScript
- React
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Development Tools
- Visual Studio Code
- Git
- GitHub
- Postman
- MongoDB Atlas
